## 2. 时间预处理：等容量 TPP 优势在三条链上均保持

以下为目标 macro-F1（%），先在每个环境内平均三个预定种子，再对三个环境等权平均。增量由未舍入的配对分数计算。

| 时间处理链 | Global-MLP | TPP | TPP − Global（百分点） | 正 / 零 / 负差 |
|---|---:|---:|---:|---|
| 历史 MAT 时间表示＋历史 merge | 48.805 | 54.883 | +6.078 | 9 / 0 / 0 |
| Native DAT 相对时间＋历史 merge | 47.496 | 56.406 | +8.910 | 8 / 0 / 1 |
| Native DAT 相对时间＋850 点线性插值 | 47.363 | 57.963 | +10.601 | 9 / 0 / 0 |

这些结果支持：在所测容量匹配模块和冻结训练协议下，TPP 的平均优势在三种时间处理链中均存在；native-merge 的一个负差也保留。不能据此断言每次运行都获益，或把收益直接归因于某条时间分支的因果机制。

在相同 native 时钟下由 merge 改为 linear，TPP 相对优势平均再增 1.690 个百分点，但九对中只有四对增加、五对减少，因此不能表述为重采样改变带来一致提升。历史链到 native 链也不是单一物理时钟缺陷的隔离实验。850 点网格随每段录制时长改变有效采样间隔，插值不等于恢复缺失动作信号。

## 3. 模态比较：相位收益取决于表示处理链

A 为单流幅度；AA 为两个独立编码器分别接收幅度；AP 为同一双流架构接收幅度和指定相位。**同网格 AA 与 AP 的比较控制双流容量**；单流 A 与双流模型容量不同。

| 网格 | 单流 A | 双流 AA | 幅度＋历史 / 历史式相位 | 幅度＋差分相位 |
|---|---:|---:|---:|---:|
| 历史网格 | 54.883 | 52.909 | 88.818 | 未设置此格 |
| Native linear 网格 | 57.963 | 56.081 | 89.267 | 54.513 |

上表是目标 macro-F1（%），每格九次运行。所有预定同网格比较如下：

| 比较 | 平均差（百分点） | 正 / 零 / 负差 |
|---|---:|---|
| 历史 AP − 历史 AA | +35.910 | 9 / 0 / 0 |
| 历史 AA − 历史 A | −1.974 | 2 / 0 / 7 |
| 历史 AP − 历史 A | +33.936 | 9 / 0 / 0 |
| Native 历史式 AP − native AA | +33.186 | 9 / 0 / 0 |
| Native 差分 AP − native AA | −1.568 | 3 / 0 / 6 |
| Native 差分 AP − native 历史式 AP | −34.754 | 0 / 0 / 9 |
| Native AA − native A | −1.882 | 4 / 0 / 5 |
| Native 历史式 AP − native A | +31.304 | 9 / 0 / 0 |

在这组实验中，历史相位和 native 历史式相位相对同容量 AA 均有明确的描述性增益；仅增加第二个幅度编码器没有带来平均增益。既有 native 差分相位相对 AA 的平均负差同样保留。因此应写“所测历史式相位表示在匹配的双流比较中提供了额外识别信息，而所测差分相位未显示平均增益”，不能泛化为所有相位形式都有效或都无效。

Native 历史式版本 `native_time_wrapped_linear_feature_unwrap_v1` 的顺序仍是：DAT 复数 CSI 取 wrapped angle → native 850 点网格上做算术线性插值 → 沿最终 90 列做 feature-axis unwrap → float32。它没有加入差分、时间轴 unwrap 或时间去均值，不是“完全修正的相位”，也不是原历史相位数组。Feature unwrap 跨接收链边界属于历史复现约定；分数较高不证明该处理具有物理校准意义。差分与历史式 AP 比较涉及完整相位表示处理链，不能把差异归因于单独的差分操作，亦不把跨网格分数差当成单因素效果。
